# Backing tracks

| File | What it is | Where it is used |
|---|---|---|
| `chime.wav` | Three ascending bell notes (C6–E6–G6) | Opens every certificate |
| `ambience.wav` | Room tone, looped | Runs underneath the whole piece at −26 dB |
| `riser.wav` | Rising filtered-noise sweep | Just before the prize is named |
| `applause.wav` | ~95 individually-modelled clappers in a hall, with cheers and whistles, looped | From the prize reveal to the end |

## Licence

All four files are **generated by this project** and carry no third-party
licence. They are synthesised from noise and sine tones by
[`scripts/generate-audio-assets.mjs`](../../scripts/generate-audio-assets.mjs),
which is seeded, so re-running it reproduces them exactly:

```
npm run assets:generate
```

This was a deliberate choice over downloading stock audio. A charity should not
have to defend the provenance of a sound file at an awards ceremony, and tuning
the character of the applause is a matter of editing numbers rather than hunting
for a different recording.

## Replacing them with real recordings

Nothing in the app cares how these files were made. To use a real recording,
overwrite the file, keeping the same name, and:

- **Use WAV, not MP3, for `ambience` and `applause`.** Both are looped, and MP3
  encoder delay and padding put a click at every loop point.
- Make the loops **statistically stationary** — no fade in or out, no build. The
  score applies its own envelope and ducking; a file that swells on its own will
  fight it.
- Mono, 48 kHz.
- **Record the licence here**, including the source URL and the licence name.

If you replace anything, listen to a whole generated certificate afterwards. The
levels in `src/lib/audio/score.ts` (`BEDS[].baseDb`) are tuned to these files and
may need adjusting.
